## How labels work (Blogger is flat)

Blogger labels are flat. The hierarchy lives in the site navigation, which nests label links. Label names carry the path, e.g. 'Sports' and 'Sports > Boxing' — a label name with ' > ' is one flat Blogger label that reads as a path in the menu.

## Filing rule (the deepest-label rule)

File every flipped story at the DEEPEST applicable label PLUS its parent labels. A boxing story files under 'Sports > Boxing' AND 'Sports'. Never file at a shallow label alone when a deeper one fits, and never invent a new label on the fly — if no label fits, file at the general level and flag the gap for the labels phase.
